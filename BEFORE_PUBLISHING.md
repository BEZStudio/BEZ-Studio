# Before publishing BEZ Studio

- [ ] Replace `support@example.com` in `assets/js/config.js`.
- [ ] Configure Firebase if you want real accounts.
- [ ] Enable Email/Password authentication in Firebase.
- [ ] Add your GitHub Pages/custom domain to Firebase Authorized domains.
- [ ] If using Firebase Storage, publish `firebase-storage.rules`.
- [ ] Keep all private passwords/tokens out of the repo.
- [ ] Add only your real games to `assets/data/games.json`.
- [ ] Test signup, verification, login and password reset using a test account.
- [ ] Test every game download on another Windows computer.
- [ ] Scan packaged releases before uploading them.
- [ ] Review Terms/Privacy text for your actual service and country before a public launch.
- [ ] If you collect data from users, especially young users, make sure your privacy/consent setup complies with laws that apply to you.
